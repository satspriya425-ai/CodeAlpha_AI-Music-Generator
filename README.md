# 🎵AI Music Generator 

An AI-based music generation project built using Python, TensorFlow, LSTM, and Music21. The project learns patterns from MIDI music data and generates new musical sequences.

## ✨Features

- Collects MIDI music data
- Preprocesses notes and chords using Music21
- Trains an LSTM deep learning model
- Generates new musical sequences
- Converts generated sequences into MIDI
- Saves generated music as a `.mid` file

## 🛠️Technologies Used

- Python
- TensorFlow
- LSTM
- Music21
- NumPy
- Pickle
